# Projekt add2path
Projekt do obrony i do zaliczenia na AKiSO do P. mgr. inż. Gil.

Założeniem projektu jest stworzyć aplikację add2path dla systemu Linux. Program do zmiennej systemowej PATH w sposób permanentny będzie:
 - dodawać bieżący katalog, jesli go tam nie ma,
 - usuwać bieżący katalog,jesli on tam jest,
 - dodawać katalog przekazany jako parametr, jeśli go tam nie ma,
 - usuwać katalog przekazany jako parametr, jeśli on tam jest,
 - wypisywać w terminalu wykonaną operację,
 - przekazywać katalogi przez adresy względne i bezwzględne.
